Special Birthday Wish Website – Source Code. 
Thanks for downloading this. Follow these quick steps. 

One, open the project folder in VS Code or any editor. 

Two, replace names and birthday text wherever needed. 

Three replace the photos, add your own photos into the project folder and update the image file names or paths. 

Four, customize any other text or styles and save. 

Five, preview locally by opening index html in your browser. 

Six, to share online, upload the project to Netlify or Vercel. Both offer free hosting, so you can share a public link with anyone.
